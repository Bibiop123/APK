# Mes applis

Le site qui rassemble les APK de mes applis Android, avec un QR code de téléchargement pour chacune.

Site : https://bibiop123.github.io/APK/

## Ajouter une appli

Dans `applis.js`, ajouter (ou compléter) un bloc avec le nom, la description et le dépôt GitHub où ses APK sont publiés en « releases ». Le site affiche tout seul la dernière version.

## Publier une nouvelle version d'une appli

Dans le dépôt de l'appli : **Releases → Draft a new release**, un nouveau tag (`v0.2.0`…), puis glisser le fichier `.apk`. Le site se met à jour tout seul.
